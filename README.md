# PocketCloud [V4 - WIP]

A powerful **cloud infrastructure system** designed for **PocketMine-MP** servers with full **proxy support**.
PocketCloud allows you to dynamically manage multiple Minecraft Bedrock servers, proxies, and services from a centralized system.

---

## ✨ Features

* ⚡ **Dynamic Server Management** - Start, stop, and manage servers automatically
* 🌐 **Proxy Support** - Built-in support for proxy-based server networks
* 📦 **Service Templates** - Create and deploy servers using predefined templates
* 🔄 **Auto Scaling** - Automatically create new servers when needed
* 🧠 **Centralized Control** - Manage the entire network from one cloud node
* 🔐 **Secure Communication** - Encrypted communication between nodes and services
* 📊 **Monitoring System** - Track service status, player counts, and performance
* 🧩 **Plugin Friendly** - OOP-based plugin support

---

## 🏗 Architecture

PocketCloud is built around a modular architecture:

* **Cloud Node** - Main controller that manages the entire network
* **Services** - Individual server instances (lobby, minigame, etc.)
* **Proxy Layer** - Handles player routing between servers
* **Templates** - Pre-configured server setups used to create new services
